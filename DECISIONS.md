# Журнал решений

Формат записи: дата, решение, причина, отвергнутые варианты, что менять при переносе в корпоративный контур.

## D-001. Среда прототипа — одна Windows-машина
Дата: 2026-10-12
- Решение: Ollama стоит на Windows напрямую, инфраструктура (Postgres и далее) — в Docker, приложения запускаются на хосте через Gradle.
- Причина: Ollama напрямую получает доступ к GPU, приложения на хосте проще отлаживать.
- Отвергнуто: приложения в контейнерах; локальный GitLab CE (не хватит ОЗУ рядом с моделью на 18 ГБ).
- Перенос: все адреса и имена контейнеров — в конфигурации.

## D-002. Java 17, Gradle 7.3.3, граница по дате 20.02.2022
Дата: 2026-10-12
- Решение: Java 17 (Liberica 17.0.10), Gradle wrapper 7.3.3. Библиотеки не новее 20.02.2022, правило действует и на транзитивные зависимости. Исключения только по согласованию с пользователем. Проверка дат — вручную по Maven Central.
- Причина: во внутреннем репозитории артефактов нет более новых версий; проверить наличие версий в нём нельзя.
- Отвергнуто: Java 21, Spring Boot 3.x (jakarta.*).
- Перенос: на корпоративной машине версию Gradle подтверждает пользователь. В системе `JAVA_HOME` указывает на JDK 11 — Gradle должен работать на 17.

## D-003. Модели по ролям
Дата: 2026-10-12
- Решение: роль heavy — qwen3-coder:30b, light — qwen2.5:7b, embedding — bge-m3 (1024). Имена моделей и размерность — только в конфигурации. В схеме БД vector(1024); смена модели эмбеддингов означает пересоздание колонки и полную переиндексацию. Эндпоинт эмбеддингов — /api/embed. num_ctx задаётся явно, от 32k.
- Отвергнуто: llama3.2:3b (слабее на русском), deepseek-r1:7b (нет вызова инструментов), nomic-embed-text (768 измерений, не выбран).
- Перенос: роли и имена моделей на корпоративной платформе — в конфигурации.

## D-004. Абстракция модели
Дата: 2026-10-12
- Решение: LlmPort и EmbeddingPort с нейтральными DTO в core; Ollama (родной API) — первая реализация, OpenAI-совместимая — позже.
- Причина: корпоративная платформа, скорее всего, использует формат OpenAI.
- Перенос: PORTING: параметры вроде num_ctx у Ollama задаются в запросе, на корпоративной платформе — иначе.

## D-005. PostgreSQL 15 и pgvector
Дата: 2026-10-12
- Решение: PostgreSQL 15 + pgvector, не самые новые версии; точный тег образа подбираем на шаге 1.1.
- Причина: поддержка PostgreSQL 14 заканчивается в ноябре 2026.
- Перенос: версию PostgreSQL и наличие pgvector в корпоративном контуре выясняет пользователь.

## D-006. gitlab.com как ahcode
